# dicts/math-terms.dict.txt —— 数学专名自定义词典（AI:PRD-004 · 004-A）
#
# ════════════════════════════════════════════════════════════════════════════
# 这是什么
#   jieba 的通用词典不认中小学数学专名，会把它们切碎成没有检索价值的碎片：
#     等腰三角形 → 等腰三角 / 形      （「等腰三角」不是词，「形」是噪声，
#                                       而真正该能查到的「三角形」压根没出现）
#     有序数对   → 有 / 序数 / 对      （切法完全错）
#     科学记数法 → 科学 / 记数法       （搜「科学」会把这类题全捞出来）
#     加减消元法 → 加 / 减消 / 元法    （「减消」「元法」都是废 token）
#   本文件把这些专名喂给分词器，让它们在索引与查询里都保持一个整词。
#
# 起步词表怎么来的（🔴 出处可查，不是拍脑袋编的）
#   全部从**本库现有语料**里萃取：`kp.name`（考点名 415 条）+ `kp_alias.alias`
#   （别名 122 条）→ 按分隔符（·、，（）与及和）与「的」切出头部专名 →
#   只留 `Jieba.cut()` **会切碎**的（不切碎的说明通用词典本来就认识，入典没有意义）
#   → 人工筛掉短语/动宾结构（「求代数式的值」「全等三角形的判定」「由平行四边形」
#   这类不是专名，是句子）。每行尾注写着它从哪条考点/别名来。
#
# 格式（jieba dict.txt 同款）
#   词  词频  词性        `#` 起的注释与空行由 core/segment.ts 的加载器剥掉，
#                         剥完才喂给 jieba —— jieba-rs 的 load_dict 不吃注释行。
#   词频统一 50：3 太低压不过「一般」这类高频通用词（实测「一般式」还是被切开），
#   50 够胜出又远低于通用词量级（「的」在官方词典里是百万级），不会把邻接的字硬吸进来。
#   词性统一 n，本产品不用词性。
#
# 🔴 加词的两条纪律
#   ① **加词不会让召回变低**——不是因为词选得好，是因为写侧 `segSearch` 走
#      「自定义词典 ∪ 基础词典」并集（见 core/segment.ts §双词典并集）。
#      所以这里选词只需回答「它是不是一个数学专名」，不必权衡会不会切丢子词。
#   ② 加完必跑 `scripts/resegment-nodejieba-20260813.ts`（或它的后继）重派生存量，
#      **否则新词只对新题生效**，老题的索引还是旧切法 —— 又一次静默半失效。
# ════════════════════════════════════════════════════════════════════════════
